# Hero Banner Videos Directory

Place your 10-second hero banner video files in this folder.

### Recommended specifications:
- **Filename**: `hero-banner.mp4` (accessible at `/videos/hero-banner.mp4`)
- **Format**: MP4 (H.264 codec) or WebM
- **Duration**: ~5 to 12 seconds seamless loop
- **Resolution**: 1080p (1920x1080) or 720p (1280x720)
- **Audio**: Muted (strip audio tracks to save ~30% file size)
- **Target File Size**: Under 3MB–5MB for instant mobile loading

Once placed here, you can select or paste `/videos/hero-banner.mp4` in the LOOMSDAY Admin Panel CMS under **Storefront CMS → Homepage Hero**.
